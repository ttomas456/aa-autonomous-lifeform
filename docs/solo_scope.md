# Solo Scope Note

This project was built as a solo submission.

The scope is intentionally focused on a polished 2D autonomous lifeform rather than a larger 3D or XR scene. The main effort is in making the dogs feel alive through layered systems:

- autonomous state selection
- steering movement
- needs and personality
- memory and trust
- procedural animation
- procedural audio
- player interactions
- debug visualisation

The 2D style keeps the project achievable while still matching the assignment brief, which allows 2D, 3D, or holographic artificial lifeforms.
