# Reflection Notes

The strongest learning from this project was that believable life does not need one huge AI system. It comes from several small systems reinforcing each other.

The needs system gives the dogs internal pressure. The FSM turns that pressure into visible decisions. Steering makes the decisions look smooth. Memory changes how the dogs respond to the player over time. Procedural animation, particles, and sound make the internal state readable.

The project stayed 2D because the assignment allows 2D lifeforms and because polish, interaction, and autonomous behaviour were more important than a rushed 3D conversion.
