# Build Notes

The project is designed for a desktop Godot export.

## Recommended Export Steps

1. Open the project in Godot 4.5.
2. Confirm `scenes/main.tscn` is the configured main scene.
3. Add a desktop export preset for the target machine.
4. Export the build.
5. Launch the exported build and run the testing checklist.
6. Record the demo video from the exported build.

## Video Notes

The assignment asks for a video from a build rather than the editor. Keep the video focused on the agent systems and show both normal gameplay and debug gizmos.
