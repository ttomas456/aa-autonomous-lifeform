# Marking Map

## Groovyness

- 2D garden world with animated sky, grass texture, beds, activity zones, and enrichment points.
- Procedural dogs with tail wagging, ears, state icons, emotion particles, and shadows.
- Procedural audio for barking, yips, whistle, chewing, toy squeak, snore, clicks, and background music.
- Player can interact through food, toys, petting, movement, and whistling.

## Complexity

- FSM with idle, wander, follow, seek food, play, and sleep states.
- Steering-style seek and arrive movement.
- Need model for hunger, energy, and happiness.
- Memory model for trust, excitement, and recent events.
- Distinct profiles for Buster and Cleo.
- Debug gizmos for current agent targets.

## Project Management

- Feature branch used for polish work.
- Commit history split across architecture, interaction, visuals, audio, documentation, and final polish.
- README and docs explain controls, architecture, demo plan, and source status.
