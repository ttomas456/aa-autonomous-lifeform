# Controls Quick Reference

| Input | Action |
| --- | --- |
| `WASD` / arrow keys | Move the player marker |
| Left click | Drop food |
| Right click | Drop a toy |
| `E` | Pet nearest dog |
| `Q` | Whistle to the dogs |
| `G` | Toggle debug gizmos |

Use `Q`, `E`, left click, and right click in the final video because they show the strongest interaction feedback.
